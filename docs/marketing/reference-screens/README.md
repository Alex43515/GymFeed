# GymFeed archive visual references

These images were curated from the `2024 GYM FEED` design library supplied by
the product owner. They are available to internal renderers for visual direction
and review-only campaign drafts.

They are not verified screenshots of the 2026 shipping build. Do not use them as
live-product proof in published creative. Before publication, replace every
reference image with a clean capture from the current authenticated Android or
web build and rerun marketing QA.

Excluded from the curated set:

- legacy login screens showing Apple or Facebook sign-in;
- old premium screens containing a hard-coded price;
- legacy Reels imagery that conflicts with the current workout-only FitClips
  definition;
- profile screens containing demo names or placeholder engagement counts.
